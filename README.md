# 🧹 System Tweaker & Cleaner

Консольная утилита для Windows на Python: быстрая очистка системы и диагностика ПК из одного текстового меню. Использует только стандартную библиотеку.

## Возможности

| № | Функция | Что делает |
|---|---|---|
| 1 | Очистить Temp | Удаляет файлы из папки `%TEMP%`, пропуская те, что заняты системой, и показывает ход выполнения |
| 2 | Проверить пинг | Пингует `8.8.8.8` (4 пакета) и выводит средний пинг; поддерживает русскую и английскую Windows |
| 3 | Очистить кэш DNS | Выполняет `ipconfig /flushdns` и сообщает о результате |
| 4 | Очистить корзину | Очищает корзину Windows без подтверждения |
| 5 | Проверить целостность диска | Читает статус накопителей через `wmic`, а при его отсутствии — через PowerShell (`Win32_DiskDrive`) |
| 6 | Информация о ПК | Показывает имя пользователя, процессор, объём ОЗУ и видеокарту (или несколько) |
| 7 | Выйти | Завершает программу |

При запуске без прав администратора утилита предупреждает, что часть функций (очистка DNS, системных Temp) может работать ограниченно.

## Требования

- Windows 10 / 11
- Python 3.8+
- Внешние библиотеки не нужны

> Утилита использует `ctypes.windll`, `ipconfig`, `ping -n` и PowerShell, поэтому на Linux и macOS не работает.

## Запуск

```bash
git clone <ссылка-на-репозиторий>
cd tweaker
python tweaker.py
```

Для полной функциональности запускайте терминал **от имени администратора**.

## Пример

```
========================================
         SYSTEM TWEAKER & CLEANER
========================================
1 - Очистить Temp
2 - Проверить пинг
3 - Очистить кэш DNS
4 - Очистить корзину
5 - Проверить целостность диска
6 - Информация о ПК
7 - Выйти
========================================
Выберите действие (1-7):
```

## Важно

- Очистка корзины **необратима**: файлы удаляются без подтверждения.
- Очистка Temp удаляет файлы из `%TEMP%`. Открытые программы могут пользоваться своими временными файлами, поэтому лучше закрыть их перед запуском.
- Проверка диска показывает только общий статус, который сообщает система (SMART-диагностику она не заменяет). Для детальной проверки используйте CrystalDiskInfo.
