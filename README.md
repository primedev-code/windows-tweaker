# 🧹 Windows Tweaker

Консольная утилита для Windows на Python: очистка системы и быстрая диагностика ПК из одного текстового меню. Использует только стандартную библиотеку, ставить зависимости не нужно.

## Возможности

| № | Функция | Что делает |
|---|---|---|
| 1 | Очистить Temp | Удаляет файлы из `%TEMP%`, пропуская занятые системой. Перед началом просит подтверждение, в конце показывает число удалённых и пропущенных файлов и сколько места освобождено |
| 2 | Проверить пинг | Пингует `8.8.8.8` (4 пакета) и выводит средний пинг; работает и на русской, и на английской Windows |
| 3 | Очистить кэш DNS | Выполняет `ipconfig /flushdns`, результат определяется по коду возврата |
| 4 | Очистить корзину | После подтверждения очищает корзину и различает три случая: очищена, уже пуста, ошибка (с кодом) |
| 5 | Проверить целостность диска | Через PowerShell (`Win32_DiskDrive`) показывает модель и статус каждого диска и общий вердикт |
| 6 | Информация о ПК | Имя пользователя, процессор, объём ОЗУ и видеокарта (или несколько) |
| 7 | Выйти | Завершает программу |

При запуске без прав администратора утилита предупреждает, что часть функций (очистка DNS и системных Temp) может работать ограниченно. На не-Windows системах она сразу сообщает об этом и завершается.

## Требования

- Windows 10 / 11 (PowerShell 5.1+ входит в систему)
- Python 3.8+
- Внешние библиотеки не нужны

## Запуск

```bash
git clone <ссылка-на-репозиторий>
cd windows-tweaker
python tweaker.py
```

Для полной функциональности запускайте терминал **от имени администратора**.

## Пример

```
========================================
         SYSTEM TWEAKER & CLEANER
========================================
1 - Очистить Temp
2 - Проверить пинг
3 - Очистить кэш DNS
4 - Очистить корзину
5 - Проверить целостность диска
6 - Информация о ПК
7 - Выйти
========================================
Выберите действие (1-7):
```

## Как это устроено

- Меню собрано из словаря `MENU`: чтобы добавить новый пункт, достаточно написать функцию и добавить одну строку.
- Вызовы внешних команд вынесены в хелперы `run()` и `ps_query()`.
- Для очистки корзины используется WinAPI `SHEmptyRecycleBinW` через `ctypes`; код результата (HRESULT) проверяется явно.
- Состояние дисков берётся из `Win32_DiskDrive` через PowerShell. Устаревший `wmic` не используется.

## Важно

- Очистка корзины **необратима**: файлы удаляются безвозвратно (программа спрашивает подтверждение).
- Перед очисткой Temp лучше закрыть открытые программы, чтобы не потерять их временные данные.
- Проверка диска показывает только общий статус, который сообщает система. Это не замена SMART-диагностике, для неё используйте CrystalDiskInfo.
